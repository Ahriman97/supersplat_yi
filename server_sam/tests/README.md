# Тесты SAM-сервера

## Что проверяется

Smoke-тест проверяет, что сервер SAM развёрнут корректно и отвечает на запросы:

1. `/health` — сервер жив, статус `ok`.
2. `/segment` — принимает картинку и координаты клика, возвращает маску.
3. Маска непустая (минимум 100 байт).
4. `X-SAM-Score` ≥ 0.7 — модель уверена в результате.
5. `X-SAM-Time` ≤ 10 сек — ответ приходит за разумное время.

## Как запустить

### 1. Убедиться, что сервер запущен

```bash
cd server_sam
docker compose up -d   # -d = в фоне
docker compose ps      # проверить, что контейнер запущен
